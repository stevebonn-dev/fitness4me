🍎 Apple Health Setup Instructions

Method 1: Health Auto Export (Recommended)

  1. Download Health Auto Export from the App Store
  2. Open the app and grant Health permissions
  3. Go to "Automations" → "Create New"
  4. Select metrics: HRV, Sleep Analysis
  5. Set export format to "JSON"
  6. Choose export location: iCloud Drive or Dropbox
  7. Set automation to run daily or on-demand
  8. In Fitness4Me, tap "Import Apple Health JSON File" and select the exported file

Method 2: iOS Shortcut (Advanced)

  1. Open the Shortcuts app on your iPhone
  2. Tap "+" to create a new shortcut
  3. Name it "Sync to Fitness4Me"
  4. Add action: Find Health Samples
  5. Configure for HRV (most recent) and Sleep (last night)
  6. Add action: Get Dictionary Value for each metric
  7. Add action: Text with format: https://your-domain.com/fitness4me?hrv=[HRV]&sleep=[Sleep]
  8. Add action: Open URL
  9. Save and add to your Home Screen or Apple Watch face
  10. Tap the shortcut to automatically sync your data

Method 3: Native App Wrapper (Developer)

For true HealthKit integration, wrap this web app using CapacitorJS: 

npm install @capacitor/core @capacitor/ios
npx cap init
npm install @capacitor/health
npx cap add ios
